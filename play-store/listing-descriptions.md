## Full description (4000 chars max)
NetGuard Pulse helps you understand mobile data use from one focused dashboard.

Monitor live app traffic, review DNS activity, set data alerts, and track hotspot usage for connected devices. It is built for people who want clearer visibility into network usage, safer DNS filtering, and timely notifications before usage gets out of hand.

Key features:

- Live app data usage with download, upload, and speed totals
- Per-app traffic list with sorting by usage or speed
- DNS activity log showing allowed and blocked domain requests
- Family DNS provider selection and parental category blocking
- Custom domain blocklist support
- Data alerts for mobile, Wi-Fi, or all network usage
- Usage history by date range and traffic category
- Hotspot client tracking with per-device usage visibility
- Hotspot session alerts for data and time thresholds
- Background hotspot alert monitoring while the app is closed

NetGuard Pulse focuses on practical network visibility. Use it to spot high-usage apps, watch background traffic, reduce unwanted domains, and receive hotspot usage alerts.

Some features rely on Android permissions and system services such as usage access, notifications, and VPN for DNS filtering. The VPN service is used for DNS filtering and domain blocking only; hotspot session alerts do not route hotspot traffic and do not turn off hotspot or mobile data. Availability can vary by Android version and device manufacturer.
